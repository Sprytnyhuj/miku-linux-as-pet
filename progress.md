# Dziennik postępu: przepisanie desktop-pet na C++/Qt6

## Zrobione
* Zbudowano `src/` (config, sprites, vdf, steam, mpris, volume, bubbles, claudechat, pet, main),
  `CMakeLists.txt`, `tests/tests.cpp`, `install.sh` (bez Pythona/venv), `README.md`.
* Messenger (QtWebEngine, MessengerHub, ChatPanel, NotifyBubble, TitleNote, log, ustawienie "messenger") pominięty.
  Klucz "messenger" w istniejącym settings.json jest zachowywany przy zapisie, ale ignorowany.
* pet.py, venv/ i web/ nietknięte; nic nie zainstalowane, działająca wersja Pythonowa nie ruszana.

## Decyzje
* MPRIS natywnie przez QtDBus (timeout 1,5 s; Previous/PlayPause/Next asynchronicznie). Ranking: grający > YouTube Music > pauza, remis = pierwszy.
* Wygląd: dymek rysowany z QPalette (Window, ramka Highlight zmieszany z Mid, PlaceholderText), przyciski/suwak to zwykłe widżety (QToolButton/QSlider) bez stylesheetów; reakcja na PaletteChange.
* Czat: własne dymki wiadomości (użytkownik: Highlight, Claude: AlternateBase, błędy: Base + ramka), pole QPlainTextEdit, wskaźnik "Claude pisze…". Rozmiar dymków liczony ręcznie (bez heightForWidth).
* Sygnały: self-pipe + QSocketNotifier. Blokada: flock w $XDG_RUNTIME_DIR/desktop-pet.lock.
* Odpowiedź API: 200 z niepoprawnym JSON -> "Błąd API (200): nieprawidłowa odpowiedź." (oryginał używał SDK, tu własna decyzja).
* Katalog `build/` zostaje w repo roboczym (do posprzątania przez użytkownika).
